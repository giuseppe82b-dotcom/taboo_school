Questo progetto nasce da una idea nata durante una lezione in cui si parlava dei 5 sensi. 
E' nata dall'idea di voler stimolare gli studenti a descrivere qualcosa usando tutti i sensi, via via è sorta la necessità di non dire delle parole.
L'esperimento è iniziato con i cibi, poi si è allargato ad altre cose su richiesta degli alunni. 


Le parole vengono lette da un file json
il file parole.json è fatto in questo modo:
ESEMPIO
[
  {
    "food": "Calcio",
    "forbidden": ["Pallone", "Porta", "Gol", "Partita", "Squadra"]
  },
  {
    "food": "Cheerleading",
    "forbidden": ["Ragazze", "Pon pon", "Acrobazia", "Piramide", "Tifo"]
  }
]

Il codice del sistema è aperto a tutti, tutti possono ampliarlo e migliorarlo.
Il codice sorgente è stato realizzato dal Prof. Brunetti dell'IC di Fino Mornasco.
